================================================================================
COMMANDS TO COMPILE AND RUN .CPP AND .CU FILES
================================================================================

This file contains all commands needed to compile and run the C++ and CUDA
files in the ParallelPauliPaths project.

================================================================================
PREREQUISITES
================================================================================

For Linux/Unix (Andrew server):
- g++ compiler (preferably g++-11)
- CUDA toolkit (version 11.7 or compatible)
- CUDA path: /usr/local/cuda-11.7

For Windows (local):
- g++ compiler (MinGW or similar)
- No CUDA support on Windows (CPU-only builds)

================================================================================
OPTION 1: BUILD WITH MAKEFILE (Linux/Unix - Full CUDA Support)
================================================================================

# Build everything (CPU + GPU)
make all

# Run the main simulator
make run

# Run tests
make test

# Clean build artifacts
make clean

# Test CUDA compilation only
make compile-test

# Check if all source files exist
make check-files

# Individual compilation commands (what Makefile does internally):

# 1. Create build directory
mkdir -p build

# 2. Compile CUDA file
nvcc -O3 -m64 --gpu-architecture compute_61 -ccbin /usr/bin/g++-11 \
     -I. -Isrc -c src/pauli_gpu.cu -o build/pauli_gpu.o

# 3. Compile C++ files
g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/pauli.cpp -o build/pauli.o
g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/main.cpp -o build/main.o
g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/tests.cpp -o build/tests.o

# 4. Link everything together
g++ -std=c++17 -Wall -O2 -o pauli_sim build/pauli_gpu.o build/pauli.o \
    build/main.o build/tests.o -L/usr/local/cuda-11.7/lib64 -lcudart

# 5. Run the executable
./pauli_sim

================================================================================
OPTION 2: WINDOWS POWERSHELL SCRIPTS (CPU-Only)
================================================================================

# Build and run main pauli simulator (CPU-only)
.\build_run_pauli.ps1

# Build and run diagnostic tool
.\build_run_diagnostic.ps1

# Build and run tests
.\build_run_tests.ps1

# Manual Windows compilation commands:

# 1. Compile main simulator (CPU-only)
g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/main.cpp src/tests.cpp -Isrc -o pauli_sim.exe

# 2. Run main simulator
.\pauli_sim.exe -d cpu

# 3. Compile diagnostic tool
g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/diagnostic.cpp -Isrc -o diagnostic.exe

# 4. Run diagnostic tool
.\diagnostic.exe

================================================================================
OPTION 3: STANDALONE PAULI PROPAGATION SIMULATOR
================================================================================

This is a standalone file that doesn't depend on the src/ directory.

# Linux/Unix
g++ -std=c++17 -Wall -O2 pauli_propogation.cpp -o pauli_propagation.exe
./pauli_propagation.exe

# Windows
g++ -std=c++17 -Wall -O2 pauli_propogation.cpp -o pauli_propagation.exe
.\pauli_propagation.exe

================================================================================
FILE DESCRIPTIONS
================================================================================

C++ Files:
- src/pauli.cpp         : Core Pauli word manipulation and gate conjugation
- src/main.cpp          : Main entry point for the simulator
- src/tests.cpp         : Test suite for verification
- src/diagnostic.cpp    : Diagnostic tool for Pauli word expansion analysis
- pauli_propogation.cpp : Standalone Pauli propagation simulator with tests

CUDA Files:
- src/pauli_gpu.cu      : GPU-accelerated Pauli operations (CUDA)

Header Files:
- src/pauli.h           : Header for pauli.cpp
- src/puali_gpu.h       : Header for pauli_gpu.cu (note: typo in filename)

================================================================================
TYPICAL WORKFLOW
================================================================================

1. ssh arulm@unix.andrew.cmu.edu
2. cd /path/to/ParallelPauliPaths
3. make clean
4. make all
5. ./pauli_sim

On Windows (CPU-only):
1. Open PowerShell in project directory
2. .\build_run_pauli.ps1
   OR
3. g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/main.cpp src/tests.cpp -Isrc -o pauli_sim.exe
4. .\pauli_sim.exe -d cpu

For standalone testing:
1. g++ -std=c++17 -Wall -O2 pauli_propogation.cpp -o pauli_propagation.exe
2. .\pauli_propagation.exe

================================================================================
COMMAND LINE OPTIONS
================================================================================

Main simulator (pauli_sim):
  -d cpu    : Use CPU-only mode
  -d gpu    : Use GPU acceleration (if available)
  --test    : Run test suite

================================================================================
NOTES
================================================================================

1. The Makefile is designed for Linux/Unix systems with CUDA support
2. Windows builds use -DCPU_ONLY flag to disable CUDA code paths
3. GPU architecture is set to compute_61 (adjust if needed for your GPU)
4. CUDA path may need adjustment based on your installation
5. The standalone pauli_propogation.cpp can be compiled independently
6. All executables are already built in the project directory
