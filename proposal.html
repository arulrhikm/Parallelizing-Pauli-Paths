Project Proposal

Parallelizing Pauli Paths

Summary

We are going to parallelize the computation of Pauli paths in quantum simulations to improve performance and scalability on parallel systems.

Background

The computation of Pauli paths is central to many quantum simulations. We plan to accelerate this by utilizing parallelism to handle the heavy computational demands.

The Challenge

Mapping Pauli path computations onto parallel systems is challenging due to the complexity of the quantum states and the irregular memory access patterns. We hope to learn more about optimizing such computations for high-performance computing environments.

Resources

We will use high-performance computing platforms with multi-core CPUs and GPUs. Starting code will be based on existing quantum simulation libraries.

Goals and Deliverables

Plan to Achieve:
  • Implement parallelization for Pauli path computations
  • Optimize for performance and scalability
  • Deliver performance benchmarks for parallelized computations

Platform Choice

We will use multi-core CPUs and NVIDIA GPUs, taking advantage of CUDA programming for GPU acceleration.

Schedule

Week 1
Set up development environment and understand existing code
Week 2
Implement basic parallelization for Pauli path computations
Week 3
Optimize memory usage and improve parallel execution
Week 4
Measure performance and finalize results
