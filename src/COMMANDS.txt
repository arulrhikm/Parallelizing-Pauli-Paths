====================================
PAULI PROPAGATION - HOW TO COMPILE AND RUN
====================================

This project contains both CPU-only and GPU-accelerated versions of the Pauli propagation simulator.
All compilation uses the Makefile in the project root directory.

====================================
PREREQUISITES
====================================

For CPU-only version:
- g++ compiler with C++17 support
- Standard C++ libraries

For GPU version (requires Linux/SSH to ghc38):
- CUDA Toolkit (tested with CUDA 11.7)
- nvcc compiler
- NVIDIA GPU with compute capability 6.1 or higher
- g++-11 or compatible C++ compiler


====================================
QUICK START - USING MAKEFILE
====================================

1. Build both executables:
   cd src
   make clean && make all
   cd ..

2. Run a test on GPU:
   ./pauli_propagation_gpu.exe 23 gpu

3. Run a test on CPU:
   ./pauli_propagation_gpu.exe 23 cpu

4. Run Python benchmark:
   python3 quick_test_stress.py

5. Generate all report figures:
   python3 generate_all_figures.py


====================================
MAKEFILE TARGETS
====================================

make all
    - Creates build/ directory
    - Compiles all .cu and .cpp files
    - Links into pauli_sim executable

make clean
    - Removes build/ directory and pauli_sim executable

make compile-test
    - Quick test: compiles only pauli_gpu.cu without linking
    - Useful for checking CUDA compilation without full build

make check-files
    - Verifies all required source files exist
    - Helpful for debugging missing file errors

make test
    - Builds and runs the test suite
    - Equivalent to: make all && ./pauli_sim --test

make run
    - Builds and runs the simulator
    - Equivalent to: make all && ./pauli_sim


====================================

Single test on GPU:

====================================
CPU-ONLY BUILD (No GPU)
====================================

If you want to build without GPU support (e.g., on Windows):

Compile tests:
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/main.cpp src/tests.cpp -Isrc -o pauli_sim.exe

Run:
    .\pauli_sim.exe -c

Note: The -DCPU_ONLY flag disables GPU code compilation.


====================================
MANUAL COMPILATION (If Makefile Fails)
====================================

If you need to compile manually without the Makefile:

1. Create build directory:
    mkdir -p build

2. Compile CUDA file:
    nvcc -O3 -m64 --gpu-architecture compute_61 -ccbin /usr/bin/g++-11 \
         -I. -Isrc -c src/pauli_gpu.cu -o build/pauli_gpu.o

3. Compile C++ files:
    g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/pauli.cpp -o build/pauli.o
    g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/main.cpp -o build/main.o
    g++ -std=c++17 -Wall -O2 -I. -Isrc -c src/tests.cpp -o build/tests.o

4. Link everything:
    g++ -std=c++17 -Wall -O2 -o pauli_sim build/pauli_gpu.o build/pauli.o \
        build/main.o build/tests.o -L/usr/local/cuda-11.7/lib64 -lcudart

====================================
TROUBLESHOOTING
====================================

"pauli_propagation_gpu.exe not found"
    - Make sure you ran: cd src && make all
    - Executable is in project root, not src/

"nvcc not found"
    - CUDA not installed or not in PATH
    - Use a machine with CUDA (e.g., ghc27.ghc.andrew.cmu.edu)

No GPU speedup:
    - Make sure you're using GPU mode: ./pauli_propagation_gpu.exe 23 gpu
    - Check nvidia-smi to verify GPU is available
    - Stress tests 23-32 show best speedup

Python script errors:
    - Make sure executable exists: ls pauli_propagation_gpu.exe
    - Install matplotlib for plots: pip install matplotlib
