====================================
PAULI PROPAGATION - HOW TO RUN
====================================

QUICK START
-----------
If already compiled (Windows PowerShell):
    .\pauli_sim.exe -d cpu
    .\diagnostic.exe


BUILD FROM SCRATCH
------------------
Compile everything (PowerShell):
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/main.cpp src/tests.cpp -Isrc -o pauli_sim.exe

Build diagnostic tool:
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/diagnostic.cpp src/pauli.cpp -Isrc -o diagnostic.exe

Alternative: use provided scripts in repository root:
    .\build_run_pauli.ps1       # build and run the main pauli simulator
    .\build_run_diagnostic.ps1  # build and run the diagnostic tool
    .\build_run_tests.ps1       # build and run tests (supports single-test index)


RUN TESTS
Run all tests (via script):
    .\build_run_tests.ps1

Run a single test (index N, 1-based):
    .\build_run_tests.ps1 -Index 23
The tests check:
- Basic Clifford gates (H, CNOT, S, T)
- Rotation gates (RX, RY, RZ)
- Multi-qubit entangled circuits
- Deep layered circuits


RUN DIAGNOSTIC
--------------
See Pauli word expansion in action (script):
    .\build_run_diagnostic.ps1

This shows how:
- Clifford gates keep Pauli word count constant
- Rotation gates cause Pauli word expansion
- Multiple rotations lead to exponential growth


CLEAN UP
--------
Remove object files (PowerShell):
    Remove-Item -Path "src\*.o" -ErrorAction SilentlyContinue
Remove executables (PowerShell):
    Remove-Item -Path "*.exe" -ErrorAction SilentlyContinue


NOTES
-----
- The -DCPU_ONLY flag compiles without GPU support
- All executables are in the src/ directory
- Tests should pass with 100% success rate
