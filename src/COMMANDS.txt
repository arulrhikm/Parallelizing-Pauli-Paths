====================================
PAULI PROPAGATION - HOW TO RUN
====================================

COMPILE AND RUN: tests.cpp
---------------------------
Compile (PowerShell):
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/pauli.cpp src/main.cpp src/tests.cpp -Isrc -o pauli_sim.exe

Run all tests:
    .\pauli_sim.exe -d cpu

Run a single test (index N, 1-based):
    .\pauli_sim.exe -d cpu -i N

Alternative (via script):
    .\build_run_tests.ps1              # build and run all tests
    .\build_run_tests.ps1 -Index N      # build and run single test (1-based index)

The tests check:
- Basic Clifford gates (H, CNOT, S, T)
- Rotation gates (RX, RY, RZ)
- Multi-qubit entangled circuits
- Deep layered circuits


COMPILE AND RUN: diagnostic.cpp
--------------------------------
Compile (PowerShell):
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 src/diagnostic.cpp src/pauli.cpp -Isrc -o diagnostic.exe

Run:
    .\diagnostic.exe

Alternative (via script):
    .\build_run_diagnostic.ps1          # build and run diagnostic tool

This shows how:
- Clifford gates keep Pauli word count constant
- Rotation gates cause Pauli word expansion
- Multiple rotations lead to exponential growth


COMPILE: pauli.cpp
-------------------
Note: pauli.cpp is a library file (no main function) and cannot be run standalone.
It must be compiled together with other source files that provide main().

Compile as object file (PowerShell):
    g++ -DCPU_ONLY -std=c++17 -Wall -O2 -c src/pauli.cpp -Isrc -o pauli.o

Or compile together with other files (see tests.cpp and diagnostic.cpp sections above).


QUICK START (If Already Compiled)
----------------------------------
Run tests:
    .\pauli_sim.exe -d cpu

Run diagnostic:
    .\diagnostic.exe


CLEAN UP
--------
Remove object files (PowerShell):
    Remove-Item -Path "src\*.o" -ErrorAction SilentlyContinue
Remove executables (PowerShell):
    Remove-Item -Path "*.exe" -ErrorAction SilentlyContinue


NOTES
-----
- The -DCPU_ONLY flag compiles without GPU support
- All executables are created in the repository root directory
- Tests should pass with 100% success rate
- pauli.cpp is a library and requires linking with files that have main() functions
